# Pain Tracker App

A comprehensive iOS application designed to help users track and manage their pain levels over time.

## Features

- **Pain Tracking**: Log and monitor your pain levels throughout the day
- **Historical Data**: View your pain history over time with intuitive visualizations
- **User Authentication**: Secure login and registration system
- **Firebase Integration**: Cloud-based data storage for accessing your information across devices

## Technology Stack

- Swift
- UIKit
- Firebase (Authentication, Firestore)
- iOS Widgets

## Requirements

- iOS 13.0+
- Xcode 11.0+
- CocoaPods

## Installation

1. Clone the repository
```bash
git clone https://github.com/DarrenBaldwin07/PainTrackerApp.git
```

2. Install dependencies using CocoaPods
```bash
pod install
```

3. Open the `.xcworkspace` file
```bash
open "Adyptaion - Pain tracker.xcworkspace"
```

4. Build and run the application

## Project Structure

- **ViewControllers/**: Contains all the view controllers for the application
- **ExtraClasses/**: Utility classes and helpers
- **IPain/**: Widget extension for iOS
- **Resources/**: Core data model and other resources
